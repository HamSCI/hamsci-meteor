# Software

The working group's software lives in its own repositories:

- [HamSCI/meteor-scatter](https://github.com/HamSCI/meteor-scatter): MSK144 meteor-ping recorder and decoder for ka9q-radio, part of the HamSCI SIGMOND station software.
- [HamSCI/MSQP](https://github.com/HamSCI/MSQP): Meteor Scatter QSO Party documents, research questions, and reference material.

Put analysis scripts for MSQP data in this folder, or add a link here to the repository that holds them.
